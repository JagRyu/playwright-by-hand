## W3D1 기다리는 확인과 정확히 맞추기 (2026-11-17 · 소요 ?분)
- 이해도: 예측 ○ · 고장 ○ · 변형 ○ · 설명 △  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - HTML 자체를 변수에 담아 `setContent` 로 페이지처럼 띄워 쓸 수 있다.
    - `{ exact: true }` 를 붙이면 대소문자까지 정확히 일치하는 글자만 찾는다.
- 🧱 막힌 곳 → 푼 방법:
    - `html` 변수에 넣은 값이 무엇인지 몰랐다 → Claude 에게 물어보고 어느 정도 이해했다.
- ❓ 아직 모르겠는 것:
    - 요소를 찾지 못할 때 메서드마다 몇 초까지 기다리는지 아직 정확히 모르겠다.
    - `setContent`, `isVisible`, `toBe` 처럼 아직 모르는 메서드가 많다.
    - `html` 변수 안의 `onclick`, `setTimeout` 이 아직 잘 이해되지 않는다.
    - `exact` 를 또 어떤 메서드에 붙여 쓸 수 있는지 모르겠다.

## W3D3 글자가 바뀔 때까지 기다리는 확인 (2026-11-19 · 소요 ?분)
- 이해도: 예측 ○ · 고장 ○ · 변형 ○ · 설명 ○  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - 괄호 안 `{ }` 에서 `Ctrl + Space` 를 누르면 넣을 수 있는 옵션 목록이 뜬다. (`toHaveText` 는 `ignoreCase`, `signal`, `timeout`, `useInnerText`)
    - `toHaveText` 는 글자 전체가 같아야 통과한다. `toHaveText('Save')` 는 `Expected: "Save"` / `Received: "Saved"` 로 실패했다.
- 🧱 막힌 곳 → 푼 방법:
    - 없음
- ❓ 아직 모르겠는 것:
    - `getByText('Save', { exact: true })` 로 찾는 것과 `toHaveText('Save')` 로 확인하는 것이 어떻게 다른지 아직 헷갈린다.
    - `await` 를 `expect` 앞에 붙일 때와 `textContent()` 앞에 붙일 때가 어떻게 다른지 아직 헷갈린다.
    - `isVisible()`, `toBeVisible()`, `toBe()` 처럼 확인에 쓰는 메서드를 아직 잘 구분하지 못하겠다.
- 📌 미룬 것:
    - `expect(page.getByTestId(...)).toHaveText(...)` 같은 구조는 코드를 더 많이 써 봐야 익숙해질 것 같다.

## W3D4 일부러 flaky 만들기 (2026-11-26 · 소요 ?분)
- 이해도: 예측 △ · 고장 ○ · 변형 ○ · 설명 ○  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - `--repeat-each=10` 같은 옵션은 `=` 앞뒤를 띄우지 않고 붙여 쓴다. 띄우면 반복이 적용되지 않는다.
    - `Saved` 가 1~4초 사이 아무 때나 생기는 화면에서 3초 고정 대기는 운에 따라 통과와 실패가 갈린다. 시간을 맞추지 말고 기다리는 확인을 써야 한다.
    - `--retries` 를 주면 실패한 테스트를 다시 돌리고, 다시 돌려 통과한 것은 `flaky` 로 따로 센다. 이 수로 어떤 테스트가 됐다 안 됐다 하는지 알 수 있다.
- 🧱 막힌 곳 → 푼 방법:
    - 없음
- ❓ 아직 모르겠는 것:
    - 화면이 어떻게 동작하느냐에 따라 어떤 확인 메서드를 골라야 하는지 아직 정확히는 모르겠다.
- 📌 미룬 것:
    - 없음

## W3D5 화면에 맞는 확인 고르기와 W3 마무리 (2026-11-26 · 소요 ?분)
- 이해도: 예측 ○ · 고장 ○ · 변형 △ · 설명 △  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - 확인은 묻는 것이 다르다. `toBeVisible()` 은 사용자 눈에 보이는지, `toHaveText()` 는 글자가 맞는지, `toBeHidden()` 은 안 보이는지를 묻는다.
    - `toHaveText()` 는 화면에 숨겨진 요소도 글자만 맞으면 통과한다. (숨긴 요소: `toHaveText` 114ms 통과 · `toBeVisible` 5.1s `Received: hidden` 으로 실패)
    - 글자로 찾았으면(`getByText`) `toBeVisible()` 로, 이름표로 찾았으면(`getByTestId`) `toHaveText()` 로 확인한다.
- 🧱 막힌 곳 → 푼 방법:
    - 느린 화면을 `waitForTimeout` 시간을 늘려 해결하려고 했다. → 화면이 늦게 뜨는 것이 정상이라면, 확인 메서드 괄호 안에 `{ timeout: n }` 을 넣어 기다리는 최대 시간을 늘린다.
- ❓ 아직 모르겠는 것:
    - 없음
- 📌 미룬 것:
    - 없음
