## W1D1 Node 실행, 변수, 함수 (2026-11-09 · 소요 ?분)
- 이해도: 예측 △ · 고장 △ · 변형 △ · 설명 △
- ✅ 알게 된 것: Const는 이미 설정한 값이 아닌 다른 값의 대입을 막는 함수이고, 변경하고자 하면 'TypeError' 라는 Error 메시지가 출력된다. 화살표 함수에서 return 값을 지정하려면 앞에 return 을 적어줘야 한다. console.log 로 함수명만 넣으면 어떤 내용의 함수인지 다 나온다. 조건 분기를 '조건?A:B' 로 작성하는 것도 배웠고, 숫자.toFixed(1) 하면 소수 자리수를 1자리로 맞출 수 있게된다. 함수가 함수 선언 방식과 화살표 함수 방식 두가지가 있는것을 알게 되었다.
- 🧱 막힌 곳 → 푼 방법: 화살표 함수에서 출력을 원한다면 return 을 넣어야 한다는 것. 나누기와 같은 간단하다고 생각했던 애들은 예외 상황을 고려하여 여러 케이스를 나눠야 한다는 것
- ❓ 아직 모르겠는 것: undefined, NaN 라고 뜨면 모르고 그냥 넘어갈 것 같은데, 빨간색 Error 코드가 아니고 왜 undefined 라고 뜨는지 모르겠다. 함수 선언 방식보다는 화살표를 코드에서 많이 보긴 했는데, 난 함수 선언 방식이 좀 손에 맞는데 왜 다들 화살표를 사용하는지 모르겠다.
- 📌 미룬 것: throw와 특별한 값 돌려주기 중 무엇을 고를지, passRate의 이상한 입력 막기
