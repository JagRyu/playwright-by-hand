## W1D1 Node 실행, 변수, 함수 (2026-11-09 · 소요 ?분)
- 이해도: 예측 △ · 고장 △ · 변형 △ · 설명 △
- ✅ 알게 된 것:
    - `const`는 다른 값을 다시 대입하는 것을 막는 키워드다. 다시 대입하면 `TypeError`가 난다.
    - 화살표 함수에 `{ }`를 쓰면 `return`을 직접 적어야 값이 돌아온다.
    - `console.log(함수명)`은 함수 내용이 아니라 `[Function: 이름]`만 보여 준다.
    - 조건 분기는 `조건 ? A : B`, 소수 자리는 `숫자.toFixed(1)`로 맞춘다.
    - 함수는 함수 선언과 화살표 함수, 두 방식으로 만들 수 있다.
- 🧱 막힌 곳 → 푼 방법:
    - 화살표 함수에서 값이 안 나왔다 → `{ }` 안에 `return`을 넣어서 해결했다.
    - 나누기처럼 단순해 보이는 계산도 0·음수 같은 예외 입력을 따로 나눠 처리해야 한다.

## W1D2 객체와 배열 (2026-11-09 · 소요 ?분)
- 이해도: 예측 · 고장 · 변형 · 설명
- ✅ 알게 된 것:
    - 데이터 모양은 배열(`[ ]`, 표), 객체(`{ }`, 한 행), 값(셀 하나) 세 가지이고, 원하는 위치를 골라 꺼낼 수 있다.
    - `throw`는 이상한 입력이 들어왔을 때 실행을 멈춰야 하는 곳에 쓴다.
    - `filter`는 배열에서 조건에 맞는 객체를 모두 골라 새 배열로 돌려준다. `find`는 조건에 맞는 첫 번째 객체 하나를 돌려준다.
    - 개수를 세려고 `count` 같은 함수를 찾았는데, `filter` 결과가 배열이라 `.length`를 붙이면 개수가 나온다.
    - `const`로 선언한 객체도 안의 값은 바꿀 수 있다. `const`가 막는 것은 변수에 다른 객체를 통째로 다시 대입하는 것이다.
- 🧱 막힌 곳 → 푼 방법:
    - `filter`·`find`에 화살표 함수를 넣어 한 번에 골라내는 게 감이 안 왔다 → 개념을 다시 읽고 적용해서 풀었다.
    - 다음에도 헷갈릴 것 같다. 반복해서 손에 익히는 게 가장 좋은 방법인 것 같다.
- ❓ 아직 모르겠는 것:
    - 값을 못 찾았을 때 `undefined`, `null`, `NaN`이 각각 어떤 상황에서 나오는지 아직 모르겠다.
    - `const` 객체 배열 안의 값을 전부 바꾸려면 하나씩 꺼내서 대입해야 하나?
