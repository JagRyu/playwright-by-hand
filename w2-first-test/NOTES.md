## W2D1 첫 테스트 실행 (2026-11-12 · 소요 ?분)

- ✅ 알게 된 것: 
    - 구조 분해로 꺼낼 때는 객체의 key 이름과 똑같이 적어야 한다. 
    - `npx playwright test` 가 실패하면 메시지의 `Expected`, `Received`, `Timeout`, `Call log` 를 보고 실패 원인을 판단할 수 있다. 
- 🧱 막힌 곳 → 푼 방법: 
    -  `w2-first-test` 폴더 안에서 `npx playwright test` 를 돌려야 하는데 상위 폴더에서 돌려서 이상한 에러가 났다 → 메시지를 지켜보고 `w2-first-test` 폴더 안에서 다시 돌려 해결했다.
- ❓ 아직 모르겠는 것: 
    -  "`test` 가 테스트를 실행할 때 새 브라우저 탭을 만들어 객체에 담아 내 함수에 넣어 준다"는 문장이 아직 이해되지 않는다. `test` 의 구조나 `page` key 를 가진 객체의 구조를 직접 본 적이 없어서인 것 같다.
    - `w2-first-test` 폴더에 `.spec.js` 파일이 여러 개일 때 그 폴더에서 `npx playwright test` 를 돌리면 어떻게 되는지 아직 안 해 봤다.

## W2D2 화면에서 찾고 확인하기 (2026-11-13 · 소요 ?분)
- 이해도: 예측 △ · 고장 △· 변형 △ · 설명 ✕  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - `getByPlaceholder()`, `getByRole()`, `fill()`, `click()` 같은 Playwright 메서드로 "Login 버튼을 클릭한다" 같은 문장을 코드로 옮겨 쓸 수 있다.
    - `await` 를 붙이면 내가 쓴 코드 한 줄이 끝날 때까지 기다린 뒤 다음 줄로 넘어간다.
- 🧱 막힌 곳 → 푼 방법:
    - 출력 예측이 아직 잘 맞지 않는다 → 예측과 실제 출력을 나란히 비교해 보니 값이 어떤 구조로 들어가는지 이해할 수 있었다.
- ❓ 아직 모르겠는 것:
    - `test` 에 내 함수(=>{...})를 넘기면 `test` 가 `{ page }` 가 든 객체를 넣어 그 함수를 실행하는 구조가 아직 익숙하지 않다. 코드를 계속 쓰다 보면 몸에 익을 것 같다.
- 📌 미룬 것: 없음

## W2D3 녹화한 코드 판정하기 (2026-11-13 · 소요 ?분)
- 이해도: 예측 △ · 고장 ○ · 변형 ○ · 설명 △  (○ 됨 / △ 반쯤 / ✕ 안 됨)
- ✅ 알게 된 것:
    - codegen 으로 녹화해 만든 Playwright 코드에는 `expect` 가 없어서, 무엇을 테스트하는지와 기대 결과를 내가 직접 정해 넣어야 한다.
    - `locator` 로 CSS 셀렉터를 적은 코드가 지저분해 보였던 이유를 Playwright 공식 문서가 권하는 순서로 알게 되었다. ① `getByRole`(사용자가 보는 그대로라서 가장 먼저 쓴다) ② `getByLabel` · `getByPlaceholder` · `getByText` ③ `getByTestId`(화면 글자가 바뀌어도 안 깨진다. 기본으로 `data-testid` 이름표를 찾는데, 테스트 대상 제품이 `data-test` 이름표를 쓴다면 `playwright.config.js` 에서 찾을 이름표를 바꿔 주면 된다) 순서로 쓰고, 이 셋으로도 찾을 수 없을 때 최후의 수단으로 `locator('CSS')` 를 쓴다. 각 메서드가 HTML 의 어느 부분(역할·글자·`placeholder`·이름표)을 보는지도 알게 되었는데, 이건 써 보면서 익숙해져야 한다.
- 🧱 막힌 곳 → 푼 방법:
    - `Add to cart` 를 누르면 상품이 장바구니에 담기고 버튼이 `Remove` 로 바뀐다. 이 버튼을 찾을 때 HTML 의 어떤 값을 써야 할지 몰라서 `page.getByRole('button', { class: '...' })` 로 썼다 → `getByRole` 은 `class` 로 찾지 못한다는 것을 알고 `locator('[data-test="..."]')` 로 바꿔, ① 장바구니에 상품이 담긴다 ② 버튼이 `Remove` 로 바뀐다 두 가지를 확인하는 테스트를 쓸 수 있었다.
- ❓ 아직 모르겠는 것:
    - `page` 에 붙는 메서드들이 HTML 의 어느 값과 짝이 맞는지 아직 바로 떠오르지 않는다. 많이 써 보면 익숙해질 것 같다.
- 📌 미룬 것: 없음
